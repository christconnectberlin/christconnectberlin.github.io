# Christ Connect Berlin · Link-Seite

Die Link-in-Bio-Seite von [@christ.connect.berlin](https://www.instagram.com/christ.connect.berlin/): Swipe-Spiel, Kiez-Welten, Termine, Anmeldung.

Live: https://christconnectberlin.github.io

## Inhalte pflegen
Alles steht oben in `index.html` im Block `CONFIG`:
- `WORLDS`: die Bezirke (Farbe, Headline, Wann/Wo/Wer/Was)
- `EVENTS`: die Termine
- `PHOTOS`: Fotos (Dateien in `img/` ablegen und hier eintragen)
- `SUBMIT_URL`: Adresse des Google Apps Scripts, das Anmeldungen ins Team-Sheet schreibt
